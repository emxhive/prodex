# Legacy Dependency Resolvers

This directory contains the legacy, language-specific dependency resolvers for Javascript/Typescript and PHP.

> [!WARNING]
> This is legacy compatibility code. 
> - **Do NOT add new universal dependency resolution work here.**
> - New dependency resolution work belongs under the universal system path: `src/dependency/**`.
> - These files are retained only to preserve current production behavior while the universal dependency resolution system is built separately.
